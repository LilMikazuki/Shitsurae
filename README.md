# Shitsurae

Menu bar app for macOS that saves Dock layouts as presets and switches between
them from a menu or a global hotkey.

Status: in development. The core package reads and writes the Dock domain and
comes with `shitsurae-cli`, a debugging tool for dumping and applying layouts.
The menu bar app itself does not exist yet.

## Requirements

- macOS 26 Tahoe or later
- Apple Silicon (M2 or newer)
- Xcode 26 or later to build

# Security

Report a vulnerability privately: open the **Security** tab of this repository
and choose *Report a vulnerability*. Do not open a public issue for it.

Only the latest release is supported. Shitsurae never uses the network and asks
for no system permissions; what it does do is write the `com.apple.dock`
preferences domain, restart the Dock, and, with Auto-Quit on, ask applications
to quit. Anything that makes it do more than that is worth a report.
